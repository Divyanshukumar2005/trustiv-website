# Changelog

All notable changes to this project are documented here.

## [1.0.0] — Initial Release

- Home, About, Services, Testimonials, Careers, and Contact pages
- Warm & vibrant design system (coral, sunflower, violet, mint on warm white)
- Mobile-responsive layout with nav toggle
- Auto-looping logo/testimonial marquee
- Testimonial "Read more" modal
- FAQ accordion on the Services page
- Contact form powered by Web3Forms
- SEO basics: sitemap.xml, robots.txt, Open Graph tags, JSON-LD structured data
